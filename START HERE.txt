VIOLIN ACOUSTIC SPECTRUM ANALYZER - HOW TO START
================================================

The app runs in your web browser, but it needs a small helper program running on your
computer to start. The helper works on this computer only: nothing is shared over the
network or the internet, and your recordings never leave your computer.

Use Chrome or Edge if you can (they remember the folder you save files to).


WINDOWS
-------
1. Unzip the project folder if it is still zipped.
2. Double-click  start.bat
3. If Windows says "Windows protected your PC", click "More info", then "Run anyway".
4. A black window opens, then the app opens in your browser.


MAC
---
1. Unzip the project folder if it is still zipped.
2. Right-click (or Control-click) the file  start.command  and choose "Open",
   then click "Open" again. (After the first time you can just double-click it.)
3. A Terminal window opens, then the app opens in your browser.

If the Mac says the file cannot be opened because it is not executable:
   open the Terminal app, type  chmod +x   (with a space after it), drag
   start.command into the Terminal window, press Return, then try step 2 again.


LINUX
-----
Open a terminal in this folder and run:   ./start.command
(If it is not executable, run  chmod +x start.command  first.)


USING THE APP
-------------
- Keep the black/Terminal window open while you use the app.
  Close that window to stop it. To use the app again, start it again.
- To record, press "Record" in the app and allow the microphone when the browser asks.
- If the browser does not open by itself, open it and go to the address shown in the
  window, usually   http://localhost:8000/
- The "Read Me" tab in the app explains how to make recordings and read the results.


IT DID NOT WORK?
----------------
- "Address already in use": the helper picks another port by itself. Use the address
  it prints in the window.
- Recording or saving does not work: make sure the address in the browser starts with
  http://localhost  (not file://), i.e. you started the app with the file above.
- Windows or Mac says the file is blocked: see the steps for your system above.
